# HR Admin

> A modern HR Admin Dashboard built with **Bun**, **React**, **TypeScript**, and **Ant Design**.

## 🧰 Tech Stack

- **Bun** – All-in-one JavaScript runtime (bundler, transpiler, package manager, test runner)
- **React 19** – UI library
- **TypeScript** – Type-safe JavaScript
- **React Router DOM** – Routing
- **Ant Design / Pro Components** – UI framework
- **Sass (optional)** – Custom styling
- **ESNext / JSX Runtime** – Latest JS features + React JSX transform
